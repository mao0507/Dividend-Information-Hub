## Context

儀表板目前把「累積股息收入」與「總投資金額」分開呈現，兩者雖然都屬於投資概況核心指標，但使用者需要在不同區塊切換視線。此次變更希望將兩者整合為單一卡片，強化資訊語意一致性，並減少版面碎片化。

## Goals / Non-Goals

**Goals:**
- 將累積股息收入與總投資金額整合為同一個儀表板卡片。
- 單一卡片維持既有資料狀態語意（例如無資料、同步中、錯誤）並保留資料時間資訊。
- 不改動後端 API 契約，僅透過既有摘要欄位完成前端重組。
- 更新前端測試以驗證新卡片渲染與舊區塊移除。

**Non-Goals:**
- 不新增任何後端欄位或 API。
- 不變更持股管理頁面的功能範圍。
- 不重做整個儀表板版面，只調整這兩個區塊的整合呈現。

## Decisions

1. 前端直接合併既有 summary 欄位渲染，不新增後端依賴。  
   - 理由：`accumulatedIncome*` 與 `totalInvestedAmount` 已存在，整合是展示邏輯問題，不應擴大成 API 變更。

2. 新卡片以「主值＋次要值＋狀態/時間」結構呈現。  
   - 理由：主值維持累積股息收入，總投資金額作為同卡片第二主資訊，保持可讀性與層級。

3. 移除舊的分離區塊，避免資訊重複。  
   - 理由：如果保留舊區塊會造成同資訊在多處顯示，降低一致性並增加維護成本。

4. 以現有測試檔更新為主，不新增額外測試框架。  
   - 理由：變更主要是 UI 結構與文案調整，沿用 `DashboardPage.spec.ts` 最小成本且可有效防回歸。

## Risks / Trade-offs

- [卡片資訊過於密集] → 透過字級與排列層級區分主次資訊，避免可讀性下降。
- [舊測試選擇器失效] → 同步更新 Dashboard 測試斷言，聚焦文字與關鍵元素存在性。
- [需求後續再拆分] → 保留計算欄位分離（僅合併 UI），未來可低成本重排版面。
