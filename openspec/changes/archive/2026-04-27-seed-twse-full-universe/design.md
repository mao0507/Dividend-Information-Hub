## Context

- 現狀：`STOCKS` 常數約 50 檔，`seed` 只做 `stock.upsert`，無自動對齊證交所最新上市家數。
- 目標：`Stock` 表在 seed 完成後，於**約定範圍**內與證交所公開「上市」證券檔數／代號集合一致，以利後續 `StockPrice` 全日行情同步有意義。
- 約束：對 TWSE 請求須節流、遵守公開資料使用禮儀；避免在 seed 內對全日行情 API 做大量逐檔請求來「數檔數」（應使用**證券基本資料／ISIN 清單**等「一覽式」來源）。

## Goals / Non-Goals

**Goals:**

- 以**單一、文件化之官方（或準官方）公開清單**為準，匯入 `Stock`（至少：`code`、`name`、`market='TWSE'`，其餘欄位依表 schema 給預設或可解析欄位）。
- Seed 結束後可驗證：`SELECT COUNT(*) FROM "Stock" WHERE "market" = 'TWSE'`（或約定 filter）與該清單**筆數一致**；並可抽樣比對代號是否存在於官方清單。
- 將匯入邏輯寫成可單元測試之純解析 + 與 Prisma 分離的函式（或獨立 script），避免日後端點微調時難以維護。

**Non-Goals:**

- 本 change **不要求** seed 同時灌入全市場歷史 `StockPrice`（仍由既有 backfill／排程負責）。
- **不強制**納入櫃買中心（TPEx）除非 proposal 後續擴充；若第一版僅 TWSE 上市，需在 spec 明示。
- 不要求每次 seed 都命中「當日秒級最新」（證交所清單每日可能微調）；以 seed 執行當下取得成功之清單快照為準，並保留離線快照選項。

## Decisions

1. **清單來源（待實作時定案其一，並寫入 `TWSE_DATA_SOURCES.md`）**  
   - **選項 A**：證交所 ISIN ／ 上市證券基本資料 CSV／HTML 解析（常見為資訊觀測站或 TWSE `isin` 頁面衍生之下載）。  
   - **選項 B**：若專案已依賴之 OpenAPI／JSON 有「全部證券代號」端點且穩定，優先採用以降低解析脆弱度。  
   - **決策原則**：以**可自動化、可重試、欄位足夠映射至 `Stock`** 為準；避免依賴僅供人閱讀之一次性 PDF。

2. **硬編碼 50 檔之處理**  
   - **預設**：全量匯入後，若仍有「示範用」額外欄位（如假 `pe`），改為僅在**無網路模式**使用精簡子集，或另建 `seed-demo.ts`；主線 `seed` 以 TWSE 清單為唯一真相來源（避免雙軌長期不一致）。

3. **網路不可用時**  
   - 支援環境變數例如 `SEED_TWSE_LIST_PATH` 指向已下載之 CSV／JSON **快照**；未設定且無網路則 seed **失敗並提示**（或僅 warning + 略過—由實作依團隊偏好定案，須寫入 spec）。

4. **產業／ETF 判斷**  
   - 若官方欄位含「市場別／ETF／產業」，映射至 `sector`、`isEtf`；缺欄時 `sector` 使用 `'未分類'` 等固定預設並於文件說明。

## Risks / Trade-offs

- **[風險] TWSE 頁面結構或 CSV 欄位變更** → **緩解**：解析單元測試固定 fixture；失敗時快速修正對應表；考慮定期快照比對。  
- **[風險] Seed 時間變長、阻塞 CI** → **緩解**：CI 使用快照檔；本機 dev 才拉線上清單。  
- **[風險] 「股數」定義與使用者認知不同（是否含 ETF）** → **緩解**：在 spec 與 README 用條列定義「納入範圍」，並提供驗證 SQL／官方對照連結。

## Migration Plan

1. 新增匯入模組與測試；本機驗證 `COUNT(*)` 與官方頁面宣告（或清單列數）一致。  
2. 將 `seed.ts` 改為呼叫匯入；保留必要之 `User`／`Dividend` 等示範資料邏輯調整順序（仍須 **Stock 先於依賴 FK 之資料**）。  
3. 若既有環境已有 50 檔：`upsert` 會更新；多出之上市檔會新增；**是否刪除已下市代號**另議（預設 **不刪**，避免誤刪歷史 `StockPrice`，或僅標記 deprecated—Open Question）。

## Open Questions

- 是否於 seed 時 **移除／停用** 已自官方清單消失之代號？（涉及 `StockPrice` 外鍵與歷史資料保留）  
- 第一版是否**僅 TWSE 上市**，櫃買另開 change？  
- 示範用 `Dividend`／假價量種子是否改為僅針對子集合，以避免無謂資料量？
